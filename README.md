## 보는 법
- → · 스페이스 · 클릭: 다음 / ←: 이전
- F 또는 오른쪽 아래 ⛶ 버튼: 전체 화면 (Esc로 나가기)
- N: 발표 노트 · G: 페이지 이동

## 파일
- `index.html`: 발표 웹PPT (16:9, 1920×1080 기준)
- `media/`: 사진·영상 (index.html과 같은 위치에 있어야 합니다)

사진 출처는 각 슬라이드 하단과 마지막 '참고 자료' 장에 표기했습니다.
